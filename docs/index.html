WELCOME

관리자 설정

신규 멤버 환영

새 멤버가 들어오면 지정 채널에 서버 안내와 링크가 포함된 환영 메시지를 자동으로 보냅니다.

  1. /설정 실행 후 환영 채널을 선택합니다.
  2. 환영 문구와 규칙·안내 링크를 입력합니다.
  3. 권한 진단 후 테스트 발송으로 확인합니다.

채널 보기·메시지 보내기·링크 임베드·파일 첨부 권한이 필요합니다. 설정은 서버 관리자만 변경할 수 있습니다.
