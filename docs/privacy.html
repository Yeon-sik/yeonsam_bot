시행일: 2026년 7월 25일

수집하는 정보

연삼이는 서버 설정 제공을 위해 Discord 서버 ID, 설정된 채널 ID, 환영 문구, 안내 링크, 게임별 패치 알림 설정을 저장합니다.

서비스 개선 지표는 서버·날짜 단위 횟수로 집계하며 개인 사용자 ID와 메시지 본문은 분석 목적으로 저장하지 않습니다.

이용 목적

저장된 정보는 환영 메시지 발송, 서버별 설정 유지, 패치 알림 전달, 오류 진단과 사용 현황 확인에만 사용합니다.

보관과 삭제

서버 설정은 기능 제공에 필요한 동안 보관하며 봇이 서버에서 제거되면 해당 서버의 설정, 구독과 서버별 지표를 삭제합니다. 별도 삭제 요청은 아래 지원 창구로 접수할 수 있습니다.

외부 서비스

패치 알림은 Valve의 Steamworks Web API에서 공개된 게임 공식 소식을 조회합니다. Discord와 Steam의 서비스 정책이 별도로 적용됩니다.
