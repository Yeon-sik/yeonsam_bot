# 로컬 봇 실행 안내

개발 도구를 몰라도 저장소 루트의 `RUN_YEONSAM_BOT.cmd`를 더블클릭하면 됩니다.

## 최초 설정

`.env` 파일에 아래처럼 토큰을 넣습니다. 토큰 값은 절대로 Git에 올리거나 채팅에 붙여 넣지 않습니다.

```env
DISCORD_BOT_TOKEN=디스코드_봇_토큰
```

기존 호환성을 위해 `TOKEN` 키도 읽지만, 새 로컬 실행 경로에서는 `DISCORD_BOT_TOKEN`을 권장합니다.

## 실행

1. `RUN_YEONSAM_BOT.cmd`를 더블클릭합니다. 기존 `start-bot.bat`을 실행해도 됩니다.
2. 잠시 후 브라우저에서 `http://127.0.0.1:8787/` 관리자 패널이 열립니다.
3. 패널에서 봇 상태를 확인하고 시작·중지·재시작·데이터 폴더 열기를 사용할 수 있습니다.
4. 실행 창을 닫으면 관리자 런처와 봇이 함께 종료됩니다.

첫 실행 때 Python 패키지가 없으면 런처가 `requirements.txt`를 사용해 자동 설치합니다. 설치 실패 시 인터넷 연결과 Python 3.11 이상 설치 여부를 확인합니다.

## 문제 해결

- `설정 필요`: `.env`의 키 이름과 값을 확인합니다.
- `오류 종료`: 관리자 패널의 최근 로그를 확인한 뒤 `봇 재시작`을 누릅니다.
- 슬래시 명령어가 보이지 않음: Discord Developer Portal에서 봇의 Members Intent를 활성화하고, 필요하면 PowerShell에서 `SYNC_GUILD_COMMANDS=true`를 설정한 뒤 런처를 다시 시작합니다.
- 패널 주소가 열리지 않음: 실행 창이 살아 있는지 확인합니다. 패널은 이 컴퓨터의 `127.0.0.1`에서만 접근하도록 제한되어 있습니다.
